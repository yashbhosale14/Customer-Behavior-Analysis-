# Customer-Behavior-Analysis-
End-to-end Customer Behavior Analysis using Python, PostgreSQL, SQL and Power BI.

## Project Description

This project is an end-to-end Customer Shopping Behavior Analysis project
developed to analyze customer purchasing patterns and generate actionable
business insights from customer shopping data.

The project follows a complete data analytics workflow, starting with raw
data preparation and exploration in Python, followed by data cleaning and
feature engineering using Pandas. The cleaned dataset is then integrated
with PostgreSQL for structured data storage and further analysis.

SQL queries are used to answer key business questions related to customer
segments, purchasing behavior, revenue, product performance, discounts,
subscriptions, shipping methods, and age groups.

The analyzed data is then connected to Power BI to create an interactive
Customer Behavior Dashboard. The dashboard provides key performance
indicators and visual analysis of revenue, customers, purchase behavior,
subscription status, product categories, age groups, locations, and payment
methods.
